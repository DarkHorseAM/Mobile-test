# Claude policies for this repo

## Deploys

Production deploys come from branch `claude/pr-monitor-app-crmVX` and are
manually promoted to production in Vercel. You are pre-authorized to merge
feature branches into `claude/pr-monitor-app-crmVX` and `git push` it
without asking — the user will handle the Vercel promote themselves.

Still ask before destructive operations on that branch (force-push, reset,
rewriting history, etc.).
